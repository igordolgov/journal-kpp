ЧТО ЭТО
-------
Фиксы по фидбеку №6:
 1. МАШИНЫ УСТУПАЮТ ДРУГ ДРУГУ «КАК ЛЮДИ». Стоящая у прохода машина (и
    машина на самом подходе к остановке) теперь отъезжает задним ходом ПО
    СВОЕЙ ОСИ, освобождая коридор проезда: въезжающая — назад по дороге
    от ворот, выезжающая — вглубь базы. Когда встречная проехала и коридор
    свободен — машина возвращается на свою остановку и ждёт своей очереди.
 2. ИСПРАВЛЕН «СКАЧОК»: въезжающая машина больше не «мгновенно оказывается
    в месте ожидания закрытия ворот». Причина: сторож через 10с стояния
    телепортировал машину на цель, занятую припаркованной встречной.
    Теперь: (а) встречная отъезжает и проход идёт плавно; (б) сторож
    телепортирует ТОЛЬКО на свободную цель и никогда — на стоящего.
 3. ВЫЕЗЖАЮЩАЯ МАШИНА ЖДЁТ ЗАКРЫТИЯ ВОРОТ НИЖЕ: точка ожидания опущена
    с 60 до 40px выше линии дороги (корпус целиком выше дороги, но заметно
    ближе к шлагбауму).
 4. Попутно убран цикл «стой-поехаль» у догоняющей отъезжающую машину —
    подход плавный.

КАК ПРИМЕНИТЬ
-------------
1. Распакуй zip В КОРЕНЬ D:\journal-kpp (с заменой файлов).
2. СРАЗУ выполни в PowerShell (D:\journal-kpp):
     git add .
     git commit -m "fix: cars yield like pedestrians, anti-teleport watchdog, exit wait 60->40"
     git push
3. Проверка: pnpm test (124 зелёных), затем pnpm dev.
4. exe пересобирать НЕ обязательно (изменения в app/), но если нужен —
   рецепт в README.md (раздел «Сборка»): Remove-Item -Recurse -Force dist-electron, .output
   -> pnpm generate -> node scripts/fix-electron-paths.mjs -> pnpm electron:build
