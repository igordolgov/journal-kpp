КАК ПРИМЕНИТЬ БЕЗ ПАТЧА — копированием файлов
==============================================

Шаг 1. Выровнять историю (2 команды в D:\journal-kpp):
   git branch backup-locmain
   git reset --hard origin/main
   (backup-locmain хранит ваш локальный коммит-черновик; после
    успешного пуша её можно удалить: git branch -D backup-locmain)

Шаг 2. Скопировать содержимое этой папки в D:\journal-kpp
   с ЗАМЕНОЙ файлов (структура папок совпадает с репозиторием).
   Три файла новые — их у вас просто не было, они добавятся:
   app/constants/builtinScene.ts
   tests/no51-exit-crossing-depth.test.ts
   tests/no52-truck-height-wheels-sound.test.ts

Шаг 3. Проверка:
   npx vitest run        → 369 passed | 1 skipped (49 файлов)

Шаг 4. Отправить:
   git add -A
   git commit -m "№51+№52: сцена по умолчанию; дорога по размерам; грузовики не выше дороги; колёса тыла; звук щелчка"
   git push origin main
