ПРИМЕНИ — фикс №7: телепорты у точек ожидания + ранний уезд машин
====================================================================

ЧТО СДЕЛАНО
-----------

1. «Телепортируется в точку ожидания» (люди И машины) — ИСПРАВЛЕНО.
   Причина найдена: сторож зависаний (stall-watchdog). Когда агент вежливо
   останавливался на подходе (уступает проезд, стоит в очереди за
   припаркованной машиной, ждёт человека на курсе), сторож через 10 секунд
   считал его «зависшим» и ПРЫГАЛ на цель — выглядело как мгновенный
   телепорт за секунду до остановки. Кроме того, у сторожа были «слепые
   зоны»: препятствие чуть сбоку (40–55px) или чуть дальше 80px он не видел.

   Исправления:
   • вежливые остановки помечаются флагом («едет за кем-то», «уступает»,
     «человек на курсе») — сторож их больше не трогает;
   • «слепые зоны» убраны: очередь в коридоре до цели видна целиком;
   • пост-гейтовый пешеход, застрявший за стоящим у прохода, получает
     «права прохода»: 3 секунды идёт без удержаний и МЯГКО дотеходит
     (раньше его прыгал сторож или лимит crossing — «скачок после калитки»);
   • лимит crossing теперь считается по времени БЕЗ ДВИЖЕНИЯ: медленно, но
     верно идущий через калитку больше не получает прыжок;
   • куча сбившихся в точку агентов расходится сама (стоящий «нелегально»
     впереди при касании корпусами не считается помехой);
   • машина, уезжающая с ворот, больше не «уступает стоя» встречной —
     дуэль приоритетов только между двумя машинами на подходе;
   • сужена полоса блокировки возврата въезжающей (полоса выезда выше
     дороги больше не держит пару «нос к хвосту» навсегда).

2. Машины не ждут полного закрытия ворот, если у ворот уже есть другая
   машина (с любой стороны) — СДЕЛАНО. Проехавшая ворота машина после
   короткой паузы (0.8с) уезжает, если у ворот стоит/проходит другая
   машина: закрывать ворота перед её носом бессмысленно — таймер всё равно
   их не закроет, пока та активна. Если у ворот пусто — прежнее ожидание
   полного закрытия.

КАК ПРИМЕНИТЬ
-------------
1. Распакуй zip В КОРЕНЬ проекта D:\journal-kpp (с заменой файлов):
   app/composables/simulator/useSimulatorPhysics.ts
   tests/antiteleport.test.ts
   tests/soak-mixed.test.ts
   tests/car-corridor-yield.test.ts
2. СРАЗУ после распаковки закоммить:
   cd D:\journal-kpp
   git add .
   git commit -m "fix: no more teleports at waiting points, cars may leave before full gate closure"
   git push
   (если push отклонён: git pull --rebase origin main && git push)
3. Проверить тесты (по желанию): npx vitest run
4. Пересборка exe (по желанию, правило сборки из README):
   Remove-Item -Recurse -Force dist-electron, .output
   pnpm generate
   node scripts/fix-electron-paths.mjs
   pnpm electron:build
   .\dist-electron\JournalKPP.exe

ЧТО ПРОВЕРИТЬ В ИГРЕ
--------------------
• человек/машина подходит к калитке/воротам — подход плавный, без рывка
  в точку ожидания (в том числе когда у прохода уже кто-то стоит);
• после калитки/ворот — без «скачка» на выходе из прохода;
• машина проехала ворота и ждёт закрытия; подъехала другая машина —
  первая уезжает, не дожидаясь закрытия;
• встречные машины у ворот уступают друг другу, никто не встаёт навсегда.
