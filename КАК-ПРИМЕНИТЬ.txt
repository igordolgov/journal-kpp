ЖУРНАЛ КПП — поставка №35: @types/node 24.1.0 -> 26.6.5
========================================================

ЧТО ЭТО
-------
Обновление типов Node.js для разработки. Сам TypeScript НЕ меняется
(остаётся ~5.9.3) — обновление до 7.0.2 сейчас невозможно, подробности
в ОТЧЁТ-№35-node-types-26.md.

Меняются 3 файла:
  package.json          @types/node: 24.1.0 -> 26.6.5
  pnpm-workspace.yaml   overrides: '@types/node': '24.1.0' -> '26.6.5'
  pnpm-lock.yaml        перегенерирован (pnpm 10.34.9)

КАК ПРИМЕНИТЬ (вариант 1 — файлы)
---------------------------------
1. Скопируйте 3 файла из папки no35-files/ поверх файлов проекта.
2. Выполните:  pnpm install
3. Проверка:   pnpm exec vue-tsc --noEmit   (ожидается: без ошибок)
               pnpm test                    (ожидается: 320 passed | 1 skipped)
               pnpm generate                (ожидается: сборка ОК)

КАК ПРИМЕНИТЬ (вариант 2 — патч)
--------------------------------
Из корня проекта:
  git apply --ignore-whitespace journal-kpp-no35-node-types.patch
  pnpm install

ПРИМЕЧАНИЯ
----------
- Обновлять нужно ОБА места: package.json И overrides в
  pnpm-workspace.yaml. В overrides @types/node был прибит к 24.1.0 —
  именно он заставил бы pnpm молча оставить старую версию, даже если
  поменять только package.json.
- Если ваш pnpm при установке снова переформатирует pnpm-lock.yaml
  (строки с "(supports-color@...)" и т.п.) — это нормальное приведение
  формата вашей версией pnpm, функционально ничего не меняет.
- Электрона это обновление не касается: он скачивается/собирается как
  прежде, @types/node влияет только на проверку типов при разработке.
