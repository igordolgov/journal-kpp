КАК ПРИМЕНИТЬ ПАТЧ №34 (выхавшая уезжает сразу — заезжающая заезжает в открытые ворота)
=====================================================================

Патч journal-kpp-no34-exit-departure.patch накладывается на состояние
ПОСЛЕ №33 (то есть на текущее состояние проекта, если все предыдущие
патчи №24Б..№33 применены).

1) Из корня проекта (где .git):
     git apply --ignore-whitespace journal-kpp-no34-exit-departure.patch

   Если файлы проекта совпадают байт-в-байт с эталоном (CRLF сохранены),
   подойдёт и обычный:
     git apply journal-kpp-no34-exit-departure.patch

   На Windows при конфликтах строк НЕ использовать git apply --3way с
   несоответствующей базой — патч проверен наложением на чистую базу
   662428f + №24Б + №25..№33 (5/5 файлов байт-в-байт), сюита на
   верификационном дереве: 320 passed | 1 skipped, 0 failed.

2) Альтернатива патчу: скопировать файлы из no34-files/ поверх проекта
   (пути совпадают со структурой репозитория).

3) Проверка:
     npx vitest run        # 320 passed | 1 skipped (43 файла)
     npx vue-tsc --noEmit  # 0 ошибок
     npm run build         # или npx nuxi generate — сборка проходит

4) Перезапустить приложение (Electron). Сценарий для проверки репорта:
   откройте ворота, выпустите грузовик и сразу отправьте к воротам
   легковую — грузовик, проехав створ (и уступив при необходимости),
   уезжает вбок через ~1с НЕ ДОЖИДАЯСЬ закрытия шлагбаума, а легковая
   свободно заезжает в открытые ворота следом.

Что внутри:
  - useSimulatorPhysics.ts — [№34-УЕЗД-СРАЗУ]: ранний уезд выезжающей
    разрешает и ПОДЪЕЗЖАЮЩАЯ въезжающая (корпус или цель в коридоре оси),
    при любом шлагбауме; предохранитель [№34-БЕЗОПАСНОСТЬ]: уезд только
    корпусом выше полосы въезда (сначала подъём корректором); оба старых
    правила сохранены — пустые ворота: ожидание закрытия ([№23]),
    обе стороны дороги заняты: уезда нет ([№27]);
  - tests/exit-pullback.test.ts — тест №27 «уезд только после закрытия»
    переписан под №34 «уезд сразу при открытом шлагбауме»;
  - tests/no34-exit-departure.test.ts — новые регрессы (грузовик +
    легковая: уезд <= 1.5с при открытых воротах, заезд следом, полный
    цикл без наложений/watchdog, уезд строго с посадки);
  - README.md, Логика-движения-агентов.txt — документация (Фикс №34,
    §14.23).
