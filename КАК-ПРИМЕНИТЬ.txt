КАК ПРИМЕНИТЬ ПАТЧ №33 (уверенный подход, ранний уезд, звук, дети, UI)
=====================================================================

Патч journal-kpp-no33-confident-children.patch накладывается на состояние
ПОСЛЕ №32 (то есть на текущее состояние проекта, если все предыдущие
патчи №24Б..№32 применены).

1) Из корня проекта (где .git):
     git apply --ignore-whitespace journal-kpp-no33-confident-children.patch

   Если файлы проекта совпадают байт-в-байт с эталоном (CRLF сохранены),
   подойдёт и обычный:
     git apply journal-kpp-no33-confident-children.patch

   На Windows при конфликтах строк НЕ использовать git apply --3way с
   несоответствующей базой — патч проверен наложением на чистую базу
   662428f + №24Б + №25..№32 (12/12 файлов байт-в-байт).

2) Альтернатива патчу: скопировать файлы из no33-files/ поверх проекта
   (пути совпадают с структурой репозитория).

3) Проверка:
     npx vitest run        # 317 passed | 1 skipped (42 файла)
     npx vue-tsc --noEmit  # 0 ошибок
     npm run build         # или npx nuxi generate — сборка проходит

4) Перезапустить приложение (Electron): звук привода ворот станет
   трескучим с редким скрипом — если захочется ГРОМЧЕ/РЕЖЕ, скажите:
   плотность треска и частота скрипа настраиваются парой констант.

Что внутри:
  - useSimulatorPhysics.ts — уверенный подход заезжающей (геометрический
    триггер crossing, пропуск отъезжающих в приоритете выезда, soft-follow
    за отъезжающим вдоль курса лидером) + ранний уезд налево при
    выезжающей без ожидания закрытия ([№33-УЕЗД-ВЫЕЗД]);
  - useAudioEngine.ts — треск зубьев шестерни + редкий скрип (gate-motor);
  - main.css — user-select: none (кнопки/label/окно симулятора);
  - useSimulatorSpawn.ts + useSimulatorIntegration.ts +
    simulatorConstants.ts — дети: спрайт 72% роста, всегда с опекуном;
  - тесты: gate-flow обновлён, +2 новых файла тестов.
