ПРИМЕНИ-ЭТО.txt — журнал КПП, пакет «возврат схемы движения: сбоку по дороге»
Коммит в репо: 3e0c0f4

ЧТО ИСПРАВЛЕНО (по твоему баг-репорту)
1. Машины больше не «стоят на капоте»: спрайт машины не вращается по
   вертикальному курсу вообще. Едет влево — нос влево (зеркало), вправо —
   нос вправо; вертикальный участок (проезд через ворота) сохраняет
   последнюю горизонтальную ориентацию, как в прежней схеме.
2. Прибывающие люди и машины снова СПАВНЯТСЯ СБОКУ (за правым краем сцены)
   и едут/идут по дороге вдоль забора, а не сверху вниз через всю сцену.
3. Уходят/уезжают как раньше: входящие — за нижний край сцены (вниз от
   ворот), ВЫХОДЯЩИЕ — ВБОК по дороге за правый край.
4. Подход к линии ворот выровнен: ноги человека (и бампер машины) ровно НА
   нижней линии калитки/ворот — не выше и не ниже.
5. Уступание симметричное: в сторону отходит теперь и ВХОДЯЩИЙ, и
   ВЫХОДЯЩИЙ (в том числе ждущий у прохода отходит, когда мимо/навстречу
   идёт человек). Стоящих в очереди и строй группы не раскидывает.

КАК ПРИМЕНИТЬ
1. Распакуй zip В КОРЕНЬ D:\journal-kpp (с заменой файлов).
   Структура: app\utils\simulatorTraffic.ts,
   app\composables\simulator\{useSimulatorSpawn,useSimulatorPhysics,useSimulatorCore}.ts,
   tests\{traffic-scheme.test.ts,pedestrian-flow.test.ts}
2. СРАЗУ после распаковки:
   git add .
   git commit -m "fix: restore side-road traffic scheme"
   git push
3. Проверка: pnpm test (должно быть 112 passed), затем pnpm dev и смотри
   симулятор.
4. Если всё ок — пересобери exe:
   Remove-Item -Recurse -Force dist-electron, .output
   pnpm generate
   node scripts/fix-electron-paths.mjs
   pnpm electron:build
   .\dist-electron\JournalKPP.exe

ТЕХНИЧЕСКИЕ ДЕТАЛИ
- Схема траекторий больше не выводится из пропорций ворот (это давало
  вертикальный поток): канон фиксированный — забор горизонтальный, город
  сверху, дорога вдоль городской стороны забора.
- Настроенные в редакторе точек маркеры применяются только если лежат на
  правильной стороне для своей роли (спавн входа — за боковым краем на
  линии дороги, уход выхода — за боковым краем и т.д.), устаревшие точки
  вертикальной схемы отбрасываются.
- Колонна группы: входящие идут за лидером по дороге (+90px), выходящие
  строятся под лидером (+80px); проход через калитку — по одному,
  точка ухода у группы общая.
- Тесты обновлены под новую геометрию: tests/traffic-scheme.test.ts
  (схема+валидация+поворот машины+уступание ждущего),
  tests/pedestrian-flow.test.ts (спавн сбоку, ноги на линии, посадка на
  линию дороги после прохода).
