ПРИМЕНИ ИСПРАВЛЕНИЯ — уступание только у ворот + машины (баг-репорт №5)

ЧТО ИСПРАВЛЕНО
==============

1) УСТУПАНИЕ ТОЛЬКО ПРИ ВХОДЕ/ВЫХОДЕ (зонное уступание)
   - Торможение перед чужим корпусом, боковое расхождение и дрейф
     «держись правее» теперь работают ТОЛЬКО у своих ворот/калитки
     (зона ~130px для людей, ~240px для машин) и в фазе самого прохода.
   - Вдали от ворот (горизонтальное движение по дороге) агенты
     проезжают/проходят СКВОЗЬ друг друга, «как раньше».

2) ДЁРГАНИЕ ПЕРЕД ОСТАНОВКОЙ (окончательный фикс)
   - В тихой зоне финального подхода (последние ~70px до точки остановки)
     боковые подталкивания ПОЛНОСТЬЮ отключены — раньше клапан
     «сосед ближе 42px» возвращал их в тихую зону, и агента дёргало
     у самой линии останова. Теперь идущий к цели двигается по прямой,
     а уступает СТОЯЩИЙ (он отходит в сторону заранее).

3) АНИМАЦИЯ ПРИ УСТУПАНИИ
   - Ждущий у прохода, отступая в сторону, теперь «ШАГАЕТ» боком:
     анимация рук и ног играет во время любого движения, включая
     уступание пути (раньше персонаж скользил с замороженными ногами).

4) ВЫЕХАВШАЯ МАШИНА ЖДЁТ ЗА ШЛАГБАУМОМ (выше на экране)
   - Точка ожидания полного закрытия ворот и линия уезда подняты
     на 60px ВЫШЕ линии дороги: машина стоит целиком за шлагбаумом,
     а не в проёме, и уезжает строго вбок по своей полосе,
     не пересекая дорогу.

5) МАШИНЫ РАЗЪЕЗЖАЮТСЯ (главный фикс)
   - Убрано ожидание «свободной стороны» — именно оно взаимно
     блокировало машины («не могут разъехаться»).
   - Въехавшая машина уезжает ВНИЗ за нижний край (каноническая схема),
     выехавшая — вбок по своей полосе ВЫШЕ дороги: их пути не
     пересекаются, уступать на дороге не нужно.
   - На дороге машины больше не тормозят друг перед другом
     (уступание — только у ворот, при въезде/выезде).

КАК ПРИМЕНИТЬ
=============
1. Распакуй zip в корень репозитория D:\journal-kpp
   (с заменой файлов; структура папок совпадает).
2. СРАЗУ закоммить:
      git add .
      git commit -m "fix: zone-gated yielding, car exit past barrier, canonical car leave, yield walk animation, no-jerk approach"
      git push
3. Проверка (опционально): npx vitest run  — 117 тестов, все зелёные.
4. Для пересборки exe (если нужен):
      Remove-Item -Recurse -Force dist-electron, .output
      pnpm generate
      node scripts/fix-electron-paths.mjs
      pnpm electron:build
      .\dist-electron\JournalKPP.exe
